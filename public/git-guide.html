نظام تتبع التغييرات — كل ما تحتاجه للعمل على مشروعك

ما هو Git؟

Git يسجل كل تعديل تسويه على ملفات مشروعك. تقدر ترجع لأي نسخة سابقة، تشتغل على أكتر من ميزة بنفس الوقت، وتشارك شغلك مع فريقك بدون ما تطيحون في بعض.

المرة الأولى — إعداد Git

git config --global user.name "اسمك"
git config --global user.email "بريدك@example.com"

هالإعداد يتسجل مرة وحدة فقط على جهازك. كل commit بعد كذا راح يكون موقع باسمك وبريدك.

بدء مشروع جديد أو ربط مشروع موجود

# بدء مستودع جديد في مجلد المشروع
git init

# نسخ مشروع موجود من GitHub
git clone https://github.com/username/repo.git

الأوامر اليومية — دورة العمل

الحالة الأمر النتيجة
شوف وش تغير git status يعرض الملفات المعدلة والجديدة والمحذوفة
جهّز ملف معين git add app.js ينقل الملف لمرحلة التجهيز (staging)
جهّز كل الملفات git add . يجمع كل التغييرات دفعة وحدة
احفظ التغييرات git commit -m "رسالة" يحفظ نسخة (لقطة) من الملفات الحالية
ارفع للسيرفر git push يرسل التغييرات المحفوظة لـ GitHub
نزّل تحديثات غيرك git pull يجلب آخر التغييرات من السيرفر ويطبقها
تلميح: فكر في git add كعربة تسوق — تحط فيها الملفات اللي تبغاها. git commit هو الدفع عند الكاشير — تسجل العملية. git push هو توصيل المشتريات للبيت — تنقلها للمكان النهائي (السيرفر).

الفروع Branches

الفرع هو نسخة منفصلة من المشروع تشتغل عليها بدون ما تأثر على النسخة الرئيسية. لما تخلص شغلك، تدمجها مع الرئيسية.

أوامر الفروع

# عرض كل الفروع
git branch

# إنشاء فرع جديد
git branch feature-login

# الانتقال لفرع
git checkout feature-login

# اختصار: إنشاء + انتقال في خطوة وحدة
git checkout -b feature-login

# دمج الفرع الحالي مع main
git checkout main
git merge feature-login

# حذف فرع (بعد دمجه)
git branch -d feature-login
انتبه: إذا غيرت الملفات وما حفظتها (commit)، بتنتقل معاك للفرع الجديد. احفظ شغلك أول أو استخدم git stash.

التراجع عن الأخطاء

الموقفالأمر
ترجّع ملف لآخر نسخة محفوظةgit restore app.js
تلغي تجهيز ملف (قبل الـ commit)git restore --staged app.js
تعدّل آخر commit (رسالة أو ملفات)git commit --amend -m "رسالة جديدة"
ترجع لـ commit قديم (تحوّل مؤقت)git checkout abc1234
ترجع ملف معين من commit قديمgit checkout abc1234 -- app.js
تخبي التغييرات الحالية (stash)git stash
ترجع التغييرات المخبأةgit stash pop

سير العمل العملي — مثال كامل

تبغى تضيف ميزة جديدة لمشروعك (مثلاً صفحة تقارير):

# 1. البداية — تأكد إنك على main ومحدث
git checkout main
git pull

# 2. أنشئ فرع للميزة الجديدة
git checkout -b feature-reports

# 3. اشتغل على الكود... بعدين جهّز التغييرات
git add .

# 4. احفظ التغييرات
git commit -m "إضافة صفحة التقارير والرسوم البيانية"

# 5. ارجع لـ main وادمج
git checkout main
git pull
git merge feature-reports

# 6. ارفع التغييرات للسيرفر
git push

# 7. نظف — احذف الفرع (اختياري)
git branch -d feature-reports

الربط مع GitHub

Git هو النظام المحلي (على جهازك). GitHub هو السيرفر السحابي اللي يخزّن نسخة من مشروعك ويخلّيك تشاركه مع غيرك.

ربط مشروع محلي مع GitHub

# 1. أنشئ repo جديد في GitHub (من الموقع)
# 2. اربطه مع مشروعك المحلي
git remote add origin https://github.com/username/repo.git

# 3. ارفع أول نسخة
git push -u origin main
