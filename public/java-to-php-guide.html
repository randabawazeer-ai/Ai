▶ 1. Hello World — أول برنامج

☕ Java
// Main.java
public class Main {
    public static void main(String[] args) {
        System.out.println("Hello World");
    }
}
🐘 PHP
// index.php
<?php

echo "Hello World";
💡
لا Class ولا main(): PHP تنفذ الكود مباشرة. لا تحتاج class أو static void main. فقط اكتب echo ويشتغل!
📝
ملاحظة: `<?php ?>` هو وسم فتح وإغلاق كود PHP داخل HTML. إذا كان الملف PHP خالص لا تحتاج لإغلاق `?>`. الكود يشتغل بدون class وبدون main method.

🏗️ 4. البرمجة الكائنية — OOP

4.1 كتابة Class (صنف)

☕ Java
public class Car {
    private String brand;
    private int year;

    public Car(String brand, int year) {
        this.brand = brand;
        this.year = year;
    }

    public String getBrand() {
        return brand;
    }
}
🐘 PHP
class Car {
    private string $brand;
    private int $year;

    public function __construct(string $brand, int $year) {
        $this->brand = $brand;
        $this->year  = $year;
    }

    public function getBrand(): string {
        return $this->brand;
    }
}
المفهوم☕ Java🐘 PHP
الـ Constructorpublic Car() {}public function __construct() {}
الوصول للـ thisthis.brand$this->brand
Public / Privatepublic int x;public int $x;
Staticstatic int count;static int $count;
استدعاء staticCar.countCar::$count أو self::$count
newnew Car("BMW", 2024)new Car("BMW", 2024)
🔑
الفرق الوحيد: Constructor اسمه __construct بدل اسم الكلاس. والوصول للـ this يحتاج -> بدل .. وكل متغير في الكلاس يبدأ بـ $.

📦 5. المصفوفات — Arrays (أقوى ميزة في PHP!)

🚀
المصفوفة في PHP = ArrayList + HashMap + Stack معًا! المصفوفة في PHP هي الـ سكين الجيش السويسري للبيانات — تقدر تستخدمها كـ List أو Map أو Stack أو Queue بدون تغيير!

5.1 إنشاء مصفوفة

☕ Java
// Array (ثابت الحجم)
int[] nums = {1, 2, 3};

// ArrayList (ديناميكي)
ArrayList<String> names = new ArrayList<>();
names.add("Ali");

// HashMap
HashMap<String, Integer> map = new HashMap<>();

🐘 PHP
// مصفوفة عادية (List)

// إضافة عنصر

// مصفوفة اسمية (Map / Dictionary)
$person = [
    'name' => 'Ali',
    'age'  => 25,
];

5.2 العمليات الشائعة

العملية☕ Java🐘 PHP
عدد العناصر list.size() count($arr)
حلقة (loop) for (var x : list) {} foreach ($arr as $x) {}
هل العنصر موجود list.contains(x) in_array($x, $arr)
فلترة list.stream().filter(...) array_filter($arr, fn($x) => $x > 0)
تحويل (map) list.stream().map(...) array_map(fn($x) => $x*2, $arr)
جمع (reduce) list.stream().reduce(0, Integer::sum) array_reduce($arr, fn($c, $x) => $c + $x, 0)
دمج مصفوفتين list1.addAll(list2) array_merge($arr1, $arr2)
فرز Collections.sort(list) sort($arr)
🗝️
مفتاح PHP: الـ Array في PHP هي أقوى هيكل بيانات. بدل 10 كلاسات في Java (ArrayList, LinkedList, Stack, Queue, HashMap...) عندك structure واحد: []. مرة تستخدمه كـ list ومرة كـ map.

🗄️ 7. قواعد البيانات — Database (PDO vs JDBC)

     PreparedStatement stmt = conn

⚠️ 8. معالجة الأخطاء — Error Handling

Try / Catch

☕ Java
try {
    int result = 10 / 0;
} catch (ArithmeticException e) {
    System.out.println(e.getMessage());
} finally {
    // cleanup
}

// throw custom
throw new RuntimeException("error!");
🐘 PHP
try {
    $result = 10 / 0;  // DivisionByZeroError
} catch (DivisionByZeroError $e) {
    echo $e->getMessage();
} finally {
    // cleanup
}

// throw custom
throw new RuntimeException('error!');
✅
نفس البنية بالضبط! try-catch-finally متطابقة. حتى throw نفس الشيء.

🌐 9. الويب — PHP ملك الويب

👑
PHP صُممت للويب! على عكس Java اللي تحتاج Servlets أو Spring Boot لتتعامل مع HTTP، PHP تتعامل مع الويب بشكل طبيعي مباشر. اكتب HTML واحط فيه كود PHP.

9.1 صفحة ويب بسيطة — مزج HTML مع PHP

<!DOCTYPE html> <html> <head> <title>صفحة PHP</title> </head> <body> <h1>أهلاً بك</h1> <?php $name = "علي"; $time = date('H:i'); echo "<p>مرحباً $name، الساعة الآن $time</p>"; ?> <?php if ($time < '12:00'): ?> <p>صباح الخير!</p> <?php endif; ?> </body> </html>

9.2 المتغيرات العالمية (Superglobals) — لا تحتاج @RequestParam!

PHP Superglobalالمحتوىيقابله في Java (Spring)
$_GET['key'] معاملات الرابط (Query String) @RequestParam
$_POST['key'] بيانات الـ Form (POST) @RequestBody / request.getParameter()
$_SESSION['key'] بيانات الجلسة (Session) HttpSession
$_COOKIE['key'] الكوكيز Cookie
$_SERVER['key'] معلومات السيرفر والـ Headers HttpServletRequest
$_FILES['file'] الملفات المرفوعة MultipartFile
$_ENV['key'] متغيرات البيئة System.getenv()
🔒
أمان: لا تستخدم $_GET أو $_POST مباشرة في استعلامات SQL! استخدم Prepared Statements دائماً. أو Eloquent في Laravel يتعامل مع هذا تلقائيًا.

05 Magic Methods

__construct, __toString, __get, __set, __call — تنفذ تلقائيًا في حالات معينة

06 Arrow Functions (PHP 7.4+)

07 Named Arguments (PHP 8)

08 Match Expression (PHP 8)

مثل switch لكن أفضل وأقصر وأنظف

09 Nullsafe Operator (PHP 8)

$user?->getAddress()?->getCity()

10 libxml / mbstring

معالجة XML + دعم ممتاز للغة العربية والترميز UTF-8

Traits — أقرب مثال لـ Default Interface Methods

☕ Java (Default Method)
interface Loggable {
    default void log(String msg) {
        System.out.println(msg);
    }
}

class User implements Loggable {
    // يستخدم log() تلقائياً
}
🐘 PHP (Trait)
trait Loggable {
    public function log(string $msg): void {
        echo $msg;
    }
}

class User {
    use Loggable; // يستدعي الـ trait
}
